# Zuroka Melys 2.0 — two voices, one rhythm

Экспериментальный музыкальный инструмент о двух людях, говорящих на разных языках. English и Japanese — два самостоятельных голоса. PERSPECTIVE меняет степень понимания: один голос становится яснее, другой — более обработанным. Ритм становится их общим языком.

## Запуск

Откройте `index.html` в современном браузере. Сервер, npm, сборка, интернет и внешние API не нужны. Звук включается после первого нажатия на ноту, барабан или PLAY. Если браузер приостановил аудио, снова нажмите ноту. Поддерживаются также VS Code Live Server и GitHub Pages: разместите все файлы вместе с `assets/`, сохраняя относительные пути. Для стерео лучше использовать наушники.

## Два синтезатора

| Голос | Клавиши | Ноты и частоты, Гц | Волны | Начальный PAN |
|---|---|---|---|---|
| 01 / English | A, S, D, F | C4 261.63; D4 293.66; E4 329.63; G4 392.00 | Sine, Triangle | −0.5 |
| 02 / Japanese | J, K, L, ; | A4 440.00; C5 523.25; D5 587.33; E5 659.25 | Square, Sawtooth | +0.5 |

Используются физические позиции клавиш: они сохраняются и при русской раскладке. Доступны мышь и мультитач. Удержание нескольких клавиш создаёт аккорд; оба голоса играют одновременно. Переключение волны применяется к уже звучащим нотам и хвостам их затухания.

У каждого голоса независимы VOLUME (0–100%), ATTACK (0.005–1.5 с), RELEASE (0.05–3 с) и PAN (−1…+1). Attack задаёт нарастание новых нот; Release — время затухания при отпускании. Volume и Pan меняются плавно, в том числе во время звучания. После атаки есть короткий спад к уровню удержания. Более яркий японский голос дополнительно ослаблен для баланса.

Источники одной ноты учитываются раздельно: отпускание мыши не выключает ту же ноту, удерживаемую клавиатурой. При потере фокуса ноты отпускаются. При скрытии вкладки секвенсор останавливается, чтобы не накапливать запоздалые удары.

## Четыре эффекта

У каждого голоса своя цепочка, а четыре центральных регулятора задают общий характер обработки:

- **DISTORTION** — WaveShaper с мягким насыщением; интенсивность управляет входным усилением и количеством обработанного сигнала. Фиксированная кривая позволяет менять обработку без её резкой замены.
- **DELAY** — задержка 270 мс и обратная связь через low-pass фильтр. Количество сигнала и feedback растут с регулятором; обратная связь ограничена 0.48.
- **REVERB** — Convolver с программно созданным двухканальным шумовым импульсом длиной 1.7 с. Регулятор меняет количество реверберации.
- **CHORUS** — задержка 16 мс, модулируемая синусоидальным LFO 0.65 Гц. Регулятор меняет глубину модуляции и количество эффекта.

Эффекты подключены параллельно к сухому сигналу и независимо суммируются. Ноль на регуляторе убирает соответствующую ветвь из выхода. Настройки интерполируются через AudioParam.setTargetAtTime.

## PERSPECTIVE

| Значение | Обработка English | Обработка Japanese |
|---|---|---|
| 0, English clearer | 0% | 100% |
| 50 | 50% | 50% |
| 100, Japanese clearer | 100% | 0% |

Это доля доступной интенсивности: `effectiveEffect = globalEffect × dirtyAmount`. Например, при Distortion 80% и Perspective 50 каждый голос получает 40% distortion. Вычисление находится в `PerspectiveController.effectiveAmounts`. Настройки эффектов не перезаписываются, PAN не меняется. При всех эффектах на нуле оба голоса остаются чистыми независимо от Perspective.

## Rhythm

Четыре кнопки слева от сетки запускают локально синтезируемые барабаны:

- KICK — синусоидальный осциллятор с падением частоты 150 → 45 Гц.
- SNARE — фильтрованный шум и тональная треугольная составляющая 180 Гц.
- HAT — шум через high-pass фильтр 7 кГц с короткой огибающей.
- CLAP — три шумовых импульса, затухающий хвост и небольшой посыл в ревербератор.

Сетка — четыре ряда по шестнадцать шагов. Нажатие включает или выключает шаг. При открытии уже есть простой редактируемый ритм. Каждый шаг длится одну шестнадцатую; полный цикл — один такт 4/4. BPM: 60–180, начальное значение 120.

PLAY начинает цикл с первого шага. Повторный PLAY не создаёт второй таймер. STOP отменяет запланированные барабанные источники и сбрасывает подсветку; естественный хвост реверберации может кратко продолжиться. Пробел вне элементов ввода и кнопок переключает транспорт. Ноты можно играть, когда регулятор находится в фокусе; стрелки управляют самим регулятором.

Планировщик просыпается каждые 25 мс и назначает звуки по `AudioContext.currentTime` на 100 мс вперёд. Таймер обслуживает планирование, а точный запуск выполняет Web Audio. Подсветка извлекает события из очереди только по достижении их аудиовремени. Изменение BPM применяется к следующим ещё не запланированным шагам; возможна задержка до окна планирования.

## Стерео и выход

English изначально смещён влево, Japanese — вправо. PAN каждого голоса доступен отдельно. Основной сигнал барабанов находится в центре; хвост хлопка немного расширяет пространство. MASTER меняет общую громкость перед DynamicsCompressor, который смягчает пики при совместной игре.

LEFT и RIGHT измеряют реальный сигнал после компрессора: ChannelSplitter → два AnalyserNode → RMS. Шкала показывает RMS с усилением отображения ×5 и ограничением до 1; это индикатор активности, а не калиброванный измеритель dBFS. Случайная анимация не используется.

```text
English oscillators → envelopes ─┬→ dry ────────────┐
                                ├→ drive / shaper ─┤
                                ├→ delay / feedback┤→ PAN L → voice level ─┐
                                ├→ convolver ──────┤                       │
                                └→ chorus / LFO ───┘                       │
Japanese oscillators → envelopes → own parallel effects → PAN R → level ───┤
Kick / Snare / Hat / Clap → drum output (+ clap room) ──────────────────────┤
                                                                          ↓
                                                  MASTER → COMPRESSOR → OUTPUT
                                                                  └→ SPLITTER
                                                                     ├→ LEFT analyser
                                                                     └→ RIGHT analyser
```

## Программные компоненты

- `AudioEngine` — единственный AudioContext, создание графа и обновление визуализации.
- `PolySynth` — полифонические ноты, огибающие, источники нажатий, переключение волн, освобождение завершённых узлов.
- `EffectsChain` — отдельные параллельные эффекты каждого голоса.
- `PerspectiveController` — вычисление результирующих интенсивностей.
- `DrumMachine` — синтез ударов, учёт и очистка источников.
- `StepSequencer` — паттерн, транспорт, аудиопланировщик и очередь визуальных событий.
- `MasterOutput` — громкость, компрессор и измерители каналов.

HTML задаёт композицию и исходные изображения; JavaScript создаёт повторяющиеся регуляторы и 64 кнопки шагов. CSS Grid и Flexbox обеспечивают две панели на десктопе и последовательные секции на мобильном. Горизонтальная прокрутка ограничена контейнером секвенсора. Исходные PNG сохранены без изменений.

## Сценарий исполнения на 45–60 секунд

1. Нажмите PLAY при 120 BPM. Включите и выключите несколько шагов HAT, затем вручную добавьте CLAP.
2. Сыграйте English: A S D F, затем удержите A + D. Переключите Sine → Triangle.
3. Ответьте Japanese: J K L ;, затем J + L. Сравните Square и Sawtooth.
4. Удерживайте A + D + J + L и плавно переведите Perspective влево, затем вправо.
5. Поднимите Delay и Reverb, уменьшите Distortion. Измените Attack и Release и сыграйте новые ноты.
6. Ускорьте ритм до 140 BPM, затем верните 120. Разведите голоса PAN и покажите реакцию двух выходных шкал.
7. Отпустите ноты и нажмите STOP, оставив естественное затухание.
